# 生态鱼池 · 3D 锦鲤池 Demo

纯静态 Three.js（r170，已内置在 `vendor/`，离线可用）小 Demo：户外生态锦鲤池。

## 运行
```bash
cd eco-pond
python3 -m http.server 8080
# 打开 http://127.0.0.1:8080/      （?q=high 强制精美画质，?q=low 强制流畅画质）
```
ES Module 需要通过 http 访问，直接双击 index.html（file://）无法加载。

## 玩法
- 点击水面投喂：鱼食落水泛起涟漪，锦鲤/金鱼游过来抢食，饱食度上升。
- 底部工具栏：生物 / 植物 / 环境 / 视角 / 投喂，同一时间只展开一个面板，Esc 关闭。
- 生物：增减锦鲤（红白、大正三色、昭和三色、丹顶、黄金、浅黄）与金鱼，撒鱼食、清理残饵。
- 植物：选择睡莲叶 / 荷花（水面）或芦苇 / 香蒲（岸边浅水），点击场景连续放置；可撤销、清空。
- 环境：时间滑块 白天→黄昏→夜晚（灯光、天空、水色变化，夜晚石灯笼亮起、萤火虫、星空），自动昼夜、水体清澈度、微风、画质。
- 视角：默认 / 俯视 / 近景 / 池边，自动环绕，沉浸欣赏（隐藏界面，Esc 退出）。
- 水面倒影：精美画质下实时平面反射（树木、石头、石灯笼、水草、萤火虫），随波纹扭曲；流畅画质或在环境面板关闭「水面倒影」时退回天空反射。
- 夜晚：锦鲤/金鱼带柔和自发光与月光轮廓光，水面夜间更通透，石灯笼光照更强，鱼在夜里也看得清。
- 存档：鱼（品种与外形种子、饱食度）、植物（类型、位置、朝向、大小）、石头布局种子、环境设置（时间、自动昼夜、清澈度、微风、萤火虫、倒影、画质、自动环绕）和水质会自动保存到 localStorage（改动后约 0.8 秒、每 15 秒及关闭页面时）。刷新即恢复。环境面板可「立即保存」或「重置鱼池（清除存档）」（需点两次确认）。地址加 `?fresh` 忽略存档且不写入。存档损坏或版本不符时载入默认鱼池，原数据备份到 `eco-pond-save-backup`。
- 生态读数：水质（鱼的数量超过承载量、残饵腐烂会降低；水生植物提高承载量并净化）、平均饱食度（随时间下降，投喂上升）。

## 文件
- `index.html`、`css/style.css`：界面（深色底部工具栏 + 面板）
- `js/main.js`：渲染器、相机、拾取、主循环
- `js/pond.js`：池形、地形、焦散池底、石头、卵石、水面着色器与涟漪
- `js/fish.js`：程序化低多边形锦鲤/金鱼、游动摆尾、群游与觅食
- `js/food.js`、`js/eco.js`：鱼食与简易生态模型
- `js/storage.js`：存档读写、版本校验与数据清洗
- `js/plants.js`、`js/scenery.js`、`js/env.js`、`js/ui.js`：植物、岸上景物、昼夜环境、界面逻辑

## v3 — 材质真实感升级 (Realism pass)

所有材质从低多边形纯色改为 PBR 贴图 + 自定义着色器：

| 对象 | 改动 |
|---|---|
| 岩石 | 细分二十面体 + fbm/脊状噪声位移、平滑法线；三平面映射 PBR（颜色/法线/粗糙度），顶面与水线处长苔藓，水线附近湿润变暗，水下藻膜；个体色差 |
| 卵石/池底 | 平滑实例化卵石（三平面贴图），池底卵石贴图 + 焦散 + 深度吸收（红光先衰减） |
| 地面/草 | 草地/泥地/卵石三区混合地形（旋转二次采样消除平铺感），岸边湿润；8500 簇弯曲草叶（每簇 12 片），颜色渐变与透光；花朵更细碎 |
| 树木 | 树皮 PBR 贴图；松树为针叶卡片，阔叶树为程序生成的 alpha 叶簇卡片（红枫/金/绿），带透光 |
| 水面 | 三层滚动法线贴图 + 细波 + 涟漪，菲涅尔，平面倒影，GGX 式太阳高光，灯笼高光，按深度/视角的吸收与散射，夜间压暗倒影 |
| 锦鲤/金鱼 | 更平滑身体、鳞片法线贴图、清漆 + 光泽(sheen) + 虹彩(黄金/浅黄更强)，半透明鳍（独立网格） |
| 睡莲/荷花/芦苇/香蒲 | 叶脉贴图与法线、蜡质清漆高光、叶缘卷曲；花瓣渐变贴图 + sheen；芦苇透光 |
| 石灯笼 | 风化地衣石材 PBR 贴图 |
| 光照 | 由天空实时烘焙 PMREM 环境贴图（时段变化时重新烘焙），ACES 色调映射，柔和阴影；白天/黄昏/夜晚均可用 |

画质档位：「流畅」使用 MeshStandard 代替 Physical、较少的草/卵石/细分、低分辨率阴影；「精致」为完整版本。存档格式未变（SAVE_VERSION 仍为 1）。

## v4 — 天气系统与性能优化

### 天气
环境面板新增：天气下拉（晴天 / 多云 / 小雨 / 中雨 / 薄雾 / 小雪）、强度滑块、自动天气开关。
- 与昼夜叠加（如雨夜）：天空变灰、阳光减弱、雾浓度、风向风力、水面波纹 rough 随天气变化。
- 雨：雨丝粒子 + 水面涟漪/水花，地面与岩石逐渐变湿（雨停后缓慢干燥）。
- 雾：近雾平面拉近，远景虚化。
- 雪：飘落雪花粒子。
- 自动天气约每 28 秒轮换预设。
- 存档版本升至 **v2**（v1 自动迁移，补默认天气字段）。

### 性能优化
- 草地：精美约 5200 簇 × 8 叶（近池优先排序），按相机高度动态裁剪 `count`；流畅约 40%。
- 倒影：分辨率约 0.32×，精美每 2 帧刷新一次；流畅关闭。
- 阴影：精美 1024 阴影图；流畅关闭投射阴影。
- 各向异性过滤：精美 ≤8，流畅 ≤2；贴图均开 mipmap。
- 黄昏默认视角补光（提高黄昏关键帧的太阳/半球光）。
- 脚本改时间时同步更新面板时钟文案。
